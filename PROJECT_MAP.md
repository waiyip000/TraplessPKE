## Choose the document for your task

- Learn the research origin: [publications](PUBLICATIONS.md) and [design evolution](DESIGN_EVOLUTION.md).
- Run the demonstration: [user manual](https://github.com/waiyip000/traplesspke-two-boundary-demo/blob/main/USER_MANUAL.md) and [owner walkthrough](https://github.com/waiyip000/traplesspke-two-boundary-demo/blob/main/WALKTHROUGH.md).
- Inspect the implementation: [protocol](https://github.com/waiyip000/traplesspke-two-boundary-demo/blob/main/PROTOCOL.md), [observation model](https://github.com/waiyip000/traplesspke-two-boundary-demo/blob/main/THREAT_MODEL.md) and [limitations](https://github.com/waiyip000/traplesspke-two-boundary-demo/blob/main/LIMITATIONS.md).
- Exchange a reviewer prediction: [peer exchange](https://github.com/waiyip000/traplesspke-two-boundary-demo/blob/main/PEER_EXCHANGE.md).
- Read tested outcomes: [dated Windows validation](https://github.com/waiyip000/traplesspke-two-boundary-demo/blob/main/VALIDATION.md) and [core acceptance scope](https://github.com/waiyip000/traplesspke-two-boundary-demo/blob/main/ACCEPTANCE.md).
- Consider protected-transport workflows: [intended-route use case](USE_CASES.md).
- Report a demo issue: [demo Issues](https://github.com/waiyip000/traplesspke-two-boundary-demo/issues), following [reporting guidance](https://github.com/waiyip000/traplesspke-two-boundary-demo/blob/main/SECURITY.md).
- Check licence scope: [research licensing](LICENSING.md), [demo LICENSE](https://github.com/waiyip000/traplesspke-two-boundary-demo/blob/main/LICENSE) and [third-party notices](https://github.com/waiyip000/traplesspke-two-boundary-demo/blob/main/THIRD_PARTY_NOTICES.md).

## Access and versions

The owner authorized public sharing of both repositories on 28 September 2026.
Both the research hub and the demonstration repository are now public. Their
cross-references can be followed without private-repository access. The demo
remains self-contained.

Original whitepaper V1.0, commercial desktop 1.1.4 and demo 0.1.2 are separate
version identities. Demo release v0.1.2 is immutable; main-branch documentation
can receive later corrections. Neither public-facing repository includes the
private commercial implementation.
