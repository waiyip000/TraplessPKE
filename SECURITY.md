# Reporting problems

Identify whether a report concerns the original whitepaper, the IEEE paper, commercial desktop 1.1.4, or a particular demonstration release. Include the version, the stated effect and the observed discrepancy.

When this repository is public, ordinary documentation and functional issues may be reported through GitHub Issues using disposable synthetic examples. Do not include passwords, reusable private keys, customer messages, unrevealed challenge answers, private commercial source or internal logs containing those materials.

No private disclosure address or response-time commitment is asserted by this repository. Do not post sensitive details publicly to compensate for an unavailable private channel. Use an established private support route if one has been provided to you.

The repository is temporarily private during the current owner review. Public reporting and demonstration-download links are not represented as available during that interval.

Read [SECURITY_SCOPE.md](SECURITY_SCOPE.md) before interpreting a local round trip or an exposure view as a broader security result.
